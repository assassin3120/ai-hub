# AI Hub（プロトタイプ）

Claude・Codex・普段使いのアプリを、左のサイドバーから切り替えて1つのウィンドウで使えるデスクトップアプリ。

## コンセプト
- **1つのウィンドウで完結**：AIとのチャットも、Gmail・Notion・カレンダーなどのアプリも、同じ画面の中で切り替えて使える。
- **アプリはプラグイン（コネクタ）として追加**：`connectors/` にファイルを1つ足すだけで、サイドバーにアプリが増える。
- **ログインはそのまま使う**：Claude / Codex はPCにログイン済みのCLIを呼び出す。Webアプリはアプリごとにログイン状態を保持する。

## 司令塔（オーケストレーション）
サイドバー一番上の「🎼 司令塔」に依頼を1つ書くと、次の流れで動きます。
1. 司令塔（Claude）が依頼を担当ごとの作業に分ける（最大5つ、前の作業の結果が必要なものは順番待ち）
2. 各作業が **担当の画面（Claude・Codex のページ）** に「🎼 司令塔より」として届き、そこで動く。順番待ちのない作業は同時に進む
3. 全部終わったら司令塔が結果をまとめる

司令塔の画面には作業ごとの状態（待機中・作業中・完了・失敗）が並び、押すとその担当の画面に移れます。作業中の担当にはサイドバーに緑の点が付きます。

## ブラウザ（ページ・動画の読み取り）
「🌐 ブラウザ」はアプリに入っている Chromium（Chrome と同じエンジン）で動くブラウザです。アドレス欄には URL も検索語も入れられます。
右側の「このページをAIに聞く」で、見ているものをそのまま AI に渡せます。
- 文字を選択していれば、その部分だけ
- YouTube の動画なら、タイトル・概要欄・字幕（日本語があれば日本語）
- それ以外のページなら本文

送り先は司令塔・おまかせ・Claude・Codex から選べます。会話の画面と Obsidian には質問とページ名・URL だけが残り、本文は AI にだけ渡ります。
ログイン状態はアプリ内で保持されますが、ふだん使っている Chrome のログインや拡張機能とは別です。

## SNS（X・Instagram を同時に見る）
「📱 SNS」を開くと、X と Instagram が横に並んで同時に見られます。それぞれ単独の画面（𝕏・📷）もあり、ログインは共通なので一度ログインすればどちらでも使えます。
並べるアプリは `connectors/sns.js` の `panes` で変えられます（例：`['x', 'instagram', 'gmail']`）。

## 自分のアプリ（温故知新リール・ダイエット・家計・映像制作レーダー）
claude.ai で作ったアプリを、そのままサイドバーから開けます。中身は claude.ai 上の本物なので、保存したデータ・Claude への質問・定期収集など、すべての機能が元のまま使えます。
claude.ai へのログインは4つで共通です（最初に一度ログインしてください）。

| 画面 | 元のアプリ |
|---|---|
| 🎞️ 温故知新リール | MV・CMのリファレンス棚、企画から探す、制約アイデアガチャ、取り込み |
| 💪 ダイエット | Ryo Body Log |
| 💴 家計・資産 | Ryoの家計ボード（キャッシュフロー、60歳の資産、案件・売上） |
| 📡 映像制作レーダー | 最新情報、新製品、FX5トラッカー、今月の流れ |

ほかの claude.ai アプリも、`connectors/` に同じ形のファイルを足せば並べられます。

## 請求書

サイドバーの「🧾 請求書」で、請求書を作って PDF に書き出せます。

- 品目・数量・単価・税率（10% / 8%）を入れると、右側に A4 の請求書がそのまま表示されます。
- 消費税はインボイス制度に合わせて、税率ごとに合計してから 1 回だけ端数を切り捨てます。
- 「源泉徴収する」にチェックすると、100 万円までは 10.21%、超えた分は 20.42% を差し引きます。
- 請求番号は請求日の年月ごとの連番（INV-202610-001）で自動で振られます。
- 「メモからAIに下書きさせる」に案件のメモを書くと、Claude が宛先・品目・金額を埋めます。
- 発行者の名前・登録番号（T＋13桁）・住所・連絡先・振込先は「設定」に一度入れておくと毎回入ります。
- 書き出した請求書は Obsidian の `AI Hub/請求書/` にも記録されます。

## Obsidian に会話を記録
設定（⚙️）で Obsidian の保管庫を選ぶと、保管庫の「AI Hub」フォルダにすべての会話を Markdown で残します。
```
AI Hub/
├─ 2026-10-20/
│   ├─ Claude.md                 … その日の Claude との会話（司令塔・おまかせ経由も含む）
│   ├─ Codex.md
│   └─ 司令塔 1342 ToDoアプリ….md  … 依頼・割り振り・各担当の結果・まとめ（担当ノートへのリンク付き）
└─ 履歴/
    ├─ Claude Code/…             … これまでの Claude Code のセッション（1セッション1ノート）
    └─ Codex/…                   … これまでの Codex のセッション
```
「これまでの会話」は `~/.claude/projects` と `~/.codex/sessions` から取り込みます。設定画面のボタンで取り込めるほか、アプリを起動するたびに自動で取り込み直すので、アプリの外で使った分も追いつきます。

設定では、Claude と Codex がファイルを読み書きする **作業フォルダ** も選べます。

## おまかせ（自動振り分け）
「✨ おまかせ」に依頼を書くと、内容から得意なAIを選んで送ります。
- コードの実装・修正・テストなど → Codex
- 文章・要約・調査・企画など → Claude
- どちらとも言えないとき → Claude（`default: true` のAI）

振り分け先と理由が表示され、「〇〇でやり直す」ボタンで別のAIに送り直せます。
得意分野は各コネクタの `strengths.keywords` で決まるので、言葉を足すだけで調整できます（判定は `router.js`）。

## アーキテクチャ
```
Electron
├─ router.js      … おまかせ振り分け（依頼文から得意なAIを選ぶ）
├─ orchestrator.js … 司令塔（計画→各担当へ割り振り→まとめ）
├─ runner.js      … CLIの実行
├─ obsidian.js    … Obsidian への記録と過去の会話の取り込み
├─ settings.js    … 設定の保存
├─ renderer/extract.js … ブラウザで開いたページ・動画から AI に渡す内容を取り出す
├─ main.js        … コネクタを読み込み、CLIを実行して出力をストリームで返す
├─ preload.js     … 画面からは安全なAPI（window.hub）だけを使えるようにする
├─ renderer/      … サイドバーと各アプリの画面
└─ connectors/    … アプリ1つにつきファイル1つ
     kind: "cli"  → チャット画面（claude -p / codex exec）
     kind: "web"  → Webアプリを埋め込み（webview）
```

### 今後のコネクタ種別（案）
- `api`：Anthropic / OpenAI のAPIを直接呼ぶ（CLIなしで使いたい場合）
- `mcp`：MCPサーバーとつなぎ、AIから他のアプリを操作できるようにする
- 横断機能：全アプリ共通のコマンドパレット（⌘K）、AIへの「今見ている画面」の受け渡し

## Electron を選んだ理由
Claude Code・Codex のCLIは Node.js 製なので同じ言語で扱いやすく、Webアプリの埋め込み（webview）も標準で使えるため。
Tauri はアプリが軽い反面、Rust が必要でWebアプリ埋め込みの制約も多いので、まずは作りやすさを優先した。

## 動かし方（Mac）
```
npm install
npm start
```
Claude / Codex を使うには、`claude` と `codex` のCLIをインストールしてログインしておく。
